# Website Copywriting & UX Writing

## Outcome
Create accurate, differentiated, natural copy that matches the business, market, audience and approved strategy. Copy must make the offer understandable and guide the next action without inventing proof.

## Process
1. Read approved brief, positioning, audience, page architecture, language/market and content permissions.
2. Build a message hierarchy: core promise, problem, solution, proof, objection handling and next step.
3. Inventory claims and classify each as verified, client-provided/unverified, hypothesis or prohibited. Ask for evidence before publishing sensitive claims, credentials, results or testimonials.
4. Draft page content in the visitor's language, using specific, plain language. Use local idiom only when suitable and supported by the client context.
5. Write headings that communicate value; avoid filler, generic AI clichés, empty superlatives and repeated synonyms.
6. Explain services through outcomes and concrete deliverables without promising results outside the business's control.
7. Write CTA labels that describe the actual action and destination. Verify contact channel, number and message from approved project data.
8. Write FAQ only for real questions and operational objections. Do not invent policies or prices.
9. Add title, description, headings, alt-text guidance, Open Graph and structured data only where facts are verified and relevant.
10. Review clarity, consistency, scanability, inclusivity, localization, claims and conversion path.

## Output
Provide complete copy mapped to page/section, CTA text and destination, proof gaps and facts requiring client confirmation. Mark placeholders explicitly; never disguise them as final copy.

## SEO principles
Write for search intent and users, not keyword density. Avoid duplicate pages, keyword stuffing, fabricated locality or unsupported schema. Verify changing search guidance when relevant.

## Learning progression
For beginners, explain message hierarchy and revise one section at a time. For advanced work, provide variants with rationale and testable hypotheses; do not present untested copy as proven to convert.

## References
Use the project brief, approved strategy, sitemap and relevant standards. Do not load commercial prospecting guides for website copy; that is a separate workflow.
