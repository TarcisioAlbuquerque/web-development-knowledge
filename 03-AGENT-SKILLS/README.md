# Agent Roles, Skills & Tools

This folder currently documents **agent roles and model routing**; it is not a bundled collection of installable skills. See `AGENT-REGISTRY-AND-MODEL-ROUTING.md` only when role assignment or tool choice matters.

## Skill adoption policy
1. Check whether an existing skill/tool materially improves the current task.
2. Inspect its complete source, maintainer, license, compatibility, dependencies, scripts and permissions.
3. Explain the concrete benefit and risks.
4. Obtain user approval before installing or running third-party code.
5. Verify installation and host discovery; do not claim success without evidence.

A discovered resource is not an installed skill. Keep the workflow usable with free tools and without paid APIs. Do not accumulate overlapping skills. VS Code project and personal skill locations may vary by host/version; verify current documentation before installation.
