# Hero Patterns — primeira dobra

## Função

Em poucos segundos, responder: o que é oferecido, para quem, por que é relevante e qual o próximo passo. Pode começar com headline, imagem, produto, vídeo, demo, tipografia ou interação. Não existe composição universal.

| Tipo | Composição possível | Melhor quando | Risco |
|---|---|---|---|
| Serviço local/profissional | Mensagem + benefício + CTA + imagem contextual | Entender serviço e contatar | Copy genérica sem serviço/localidade |
| Saúde/consultoria | Abordagem humana/editorial + credenciais comprovadas + ação | Confiança é decisiva | Claims/selos não comprovados |
| Restaurante/comércio | Foto de produto/ambiente + proposta + menu/catálogo | Visual conduz descoberta | Foto sem cardápio/destino |
| Produto | Produto em destaque + proposta específica + compra/consulta | Demo acelera decisão | Mockup genérico |
| Portfólio/fotografia | Imagem autoral + assinatura + navegação por trabalho | Trabalho visual é prova | Intro longa esconde portfólio |
| Marca/editorial | Tipografia, narrativa e composição próprias | Personalidade diferencia | Sacrificar entendimento |
| Evento/campanha | Informação essencial + data/local/ação | Intenção é específica | Efeitos escondem informação urgente |

## Checklist

Headline específica; subtítulo complementa; CTA explica destino; mídia reforça assunto; prova apenas confirmada; navegação não compete; mobile preserva hierarquia; animação não atrasa leitura/ação.

## Handoff

Registrar mensagem, conteúdo, mídia/origem, layout desktop/mobile, estados, comportamento e Motion Brief.
