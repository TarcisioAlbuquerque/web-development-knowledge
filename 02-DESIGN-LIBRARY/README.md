# Design Library

Reserved for reusable design principles, tokens, layout systems and component guidance that are not tied to one client brand.

This folder is intentionally lightweight until curated material exists. Do not copy entire third-party design systems here. Store source-specific observations in `01-REFERENCE-LIBRARY/`; store project-approved tokens and decisions in that project's private workspace.

When adding a design pattern, include purpose, context, constraints, accessibility notes, evidence/source and transfer limits. Add one route to `00-CONTEXT-SYSTEM/KNOWLEDGE-INDEX.md`.
