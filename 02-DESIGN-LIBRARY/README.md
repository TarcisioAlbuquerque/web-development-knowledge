# Design Library

Registre padrões reutilizáveis de layout, tipografia, cor, composição, imagens, motion e interação. Para cada padrão, explique problema, contexto, limitações, acessibilidade e custo técnico. Não transforme referência visual em template obrigatório.

Para landing pages, use o Visual Direction System em 08-LANDING-PAGE-ENGINE/03-DESIGN-SYSTEM/VISUAL-DIRECTION-SYSTEM.md. O sistema deve produzir tokens e regras específicas para cada projeto, não uma paleta/composição universal.

A análise de referências deve separar observação direta, descrição de terceiros, inferência e recomendação. Consulte 01-REFERENCE-LIBRARY/.
