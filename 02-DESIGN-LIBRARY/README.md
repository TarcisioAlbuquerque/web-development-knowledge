# Design Library

Store reusable design principles and systems—not arbitrary screenshots or mandatory templates.

For each pattern record:
- problem and user task it solves;
- context where it works / does not work;
- visual rules, tokens and component anatomy;
- responsive behavior and states;
- accessibility and performance constraints;
- implementation cost and maintainability;
- source/evidence and adaptation notes.

Organize future entries by pattern (typography, layout, color, imagery, navigation, forms, component, motion) and by niche only as a secondary filter. Reuse principles across industries only when brand and task fit.
