# Tools & Techniques to Verify

This is a holding list, not an endorsement or an instruction to install. Identify each item and inspect its official source before using it.

## Motion and interaction concepts
- Scroll-linked animation: animation progress is tied to scroll progress; distinguish from reveal triggered by viewport entry.
- GSAP ScrollTrigger: trigger, pin, scrub and timeline orchestration; choose only when native CSS/Web Animations/IntersectionObserver are insufficient.
- Parallax: layered movement at different rates; evaluate comfort, subject crop, mobile and reduced-motion.
- Sticky storytelling: CSS sticky or a library-assisted sequence; preserve natural scroll and escape.
- Horizontal scroll: preserve keyboard and touch access; provide vertical/mobile fallback.
- Glassmorphism: optional visual treatment; test contrast and fallback; avoid repetitive generic panels.
