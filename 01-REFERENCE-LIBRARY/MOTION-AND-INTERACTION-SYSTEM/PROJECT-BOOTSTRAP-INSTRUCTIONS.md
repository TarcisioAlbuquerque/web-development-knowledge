# Motion System — Project Bootstrap

Use only when a client project lives in a separate repository/workspace.

1. Verify the agent can access this canonical Motion & Interaction System and the Motion Starter Kit.
2. If access is unavailable, copy only the README, selected catalog rows, relevant component guidance and required starter files into the client repository. Record source commit/date.
3. Create docs/MOTION-BRIEF.md only when motion/interactions are material; otherwise add a concise motion decision to the project brief.
4. Add a short instruction to the client CLAUDE.md/AGENTS.md: "Consult the selected Motion System references and project brief; preserve content under reduced-motion and test keyboard/touch/fallback."
5. Carry the Motion Brief and implementation status in handoffs. Do not rely on shared memory between models.
6. At QA, verify each selected pattern and interaction in the real project. Unselected catalogue items are not requirements.

Do not paste the whole Motion System into client instructions. Link or copy only selected references to minimize token/context overhead. The client must own a local brief and approved behavior.
