# Guides & Playbooks

Coleção complementar de cursos, guias e playbooks externos. São fontes de apoio, não substituem automaticamente a metodologia ou os critérios de qualidade do sistema.

## Pastas
- `WEB-PRODUCTION/` — fluxo de criação, prática e publicação de sites.
- `CLIENT-ACQUISITION/` — pesquisa de leads, abordagem e comunicação comercial.
- `SOURCE-MATERIALS.md` — catálogo e rastreabilidade das fontes originais.

## Política
- Registrar origem, data, página/aula e status.
- Distinguir conteúdo original de nossa adaptação.
- Não tratar preços, ferramentas, exemplos ou funcionalidades como atuais sem verificação.
- Adaptar idioma, moeda, legislação e mercado.
- Manter o PDF original como fonte; Markdown é síntese de consulta.
