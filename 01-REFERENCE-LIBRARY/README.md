## Regra e consulta transversal

Não classificar um site por suposição. Se não for possível inspecioná-lo, registrar como pendente. Consultar por segmento e por padrão/experiência; avaliar página completa, tarefa e conteúdo, não só screenshot. Uma ficha não comprova inspeção direta.

Awwwards, Land-book e galerias são repertório, não padrão absoluto de qualidade. Extrair princípios; não copiar identidade, conteúdo, código ou assets.

## Motion & Interaction

Consulte MOTION-AND-INTERACTION-SYSTEM/README.md antes de qualquer novo projeto web. Essa pasta contém catálogo, componentes, playbook, case study, brief e bootstrap; é fonte única das regras normativas.
