# DesEngs — diretório de recursos para Design Engineers

- URL: https://desengs.com/
- Categoria: diretório curado de recursos para design engineering.
- Status: página acessada e estrutura/listagem inspecionadas em 2026-11-02.
- Uso na base: descoberta de ferramentas, bibliotecas de componentes, motion, artigos, skills e recursos de design + front-end.
- Não é, por si só, uma skill nem um instalador. É um índice para descobrir recursos; cada item deve ser avaliado e acessado individualmente antes de recomendar instalação.
- A página organiza recursos por intenção (Read, Watch, Listen, Browse, Use, Build, Learn, Join, Follow, Apply) e inclui, entre outros, bibliotecas de animação, componentes e skills para design engineers.
- Processo: localizar candidatos relevantes, abrir a fonte original, avaliar manutenção/licença/compatibilidade/dependências/segurança e só então recomendar.
- Limitação: a inclusão no diretório não equivale a auditoria ou endosso de segurança.
