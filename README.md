# Web Development Knowledge

Base central de conhecimento para planejar, criar, comercializar, entregar e evoluir websites profissionais para diferentes clientes, segmentos e tecnologias.

## Princípio central

Este repositório é a fonte oficial do conhecimento aprovado. Conversas com ChatGPT, Gemini, Claude e GitHub Copilot são ambientes de execução. A metodologia é universal e reutilizável; AURA é uma aplicação, não o único destino.

## Como começar

1. Leia AGENTS.md, 00-CONTEXT-SYSTEM/MASTER-CONTEXT.md e KNOWLEDGE-INDEX.md.
2. Identifique se a tarefa é Web Production, Client & Business Operations ou ambas.
3. Para landing pages, consulte 08-LANDING-PAGE-ENGINE/README.md.
4. Consulte workflow, especialista, padrões e referências relevantes.
5. Envie a cada IA apenas o pacote de contexto necessário.
6. Registre decisões aprovadas, entregas e handoffs.
7. Preserve materiais e decisões existentes. Peça autorização para alterações de escopo, ações destrutivas ou publicação.

## Dois fluxos integrados

**Web Production:** descoberta → briefing → estratégia → arquitetura/UX → copy → direção visual → motion → arquitetura técnica → desenvolvimento → QA → publicação.

**Client & Business Operations:** seleção de nicho → pesquisa/qualificação de leads → abordagem → reunião → proposta → fechamento → onboarding → coleta de conteúdo → gestão → entrega → pós-venda.

Nem todo projeto precisa de todas as etapas na mesma profundidade. O Assistente Mestre seleciona especialistas conforme o escopo.

## Landing Page Engine

O Engine organiza o processo específico de landing pages sem substituir a metodologia universal, a biblioteca de referências, os padrões técnicos ou o QA central. Seus módulos são guias de decisão, não templates rígidos.

## Regras essenciais

- Diferencie fatos fornecidos, evidências pesquisadas, hipóteses e recomendações.
- Registre URL, segmento, data e status de verificação das referências.
- Inspiração não autoriza copiar marca, textos, imagens, depoimentos ou código.
- Não invente dados, credenciais, avaliações, preços ou resultados.
- Avalie ferramentas e skills por necessidade, compatibilidade, licença, manutenção e segurança.
- Priorize acessibilidade, desempenho, segurança, responsividade e manutenção.
- Não afirme testes ou instalações não realizados.
- Não armazene senhas, tokens ou dados pessoais desnecessários.
- Não altere visibilidade, permissões, secrets ou configurações administrativas sem autorização explícita.
